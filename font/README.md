# Шрифты FlyEl-TRX

Здесь собраны все растровые шрифты, сохранённые в репозитории: используемые
сейчас, прежние варианты и исходный файл редактора. Папка не является архивом
только неиспользуемых шрифтов.

## Подключены в исходниках

| Файл | Назначение | Модуль отрисовки |
| --- | --- | --- |
| `font_sw2019_refined_digi.h` | Отдельно подготовленные цифры высотой 17 и 15 пикселей основной частоты | `src/lcd_digits_large.c` |
| `font_terminus_15_digi.h` | Terminus 10×15; сохранённый вариант крупных цифр | `src/lcd_digits_large.c` |
| `font_terminus_10x19_digi.h` | Terminus 10×19; сохранённый вариант крупных цифр | `src/lcd_digits_large.c` |
| `font_terminus_7x11_digi.h` | Компактная частота второго VFO | `src/lcd_digits_small.c` |
| `font_meter_4x6.h` | Цифры шкалы S-метра | `src/lcd_digits_small.c` |
| `font_channel_bold_8x9.h` | Жирные цифры номера канала | `src/lcd_digits_small.c` |
| `font_tahoma_8_prop.h` | Пропорциональный текст меню и интерфейса | `src/lcd_text.c` |
| `font_status_5x7.h` | Компактные подписи состояния | `src/lcd_text.c` |

Подключение заголовка не означает, что все его символы и функции используются
в текущем интерфейсе или попадают в итоговую прошивку.

## Прежние варианты и исходные материалы

| Файл | Назначение |
| --- | --- |
| `font_terminus_10x17_digi.h` | Прежний вариант Terminus, предшественник 10×19 |
| `font_sw2019_big_12x16_digi.h` | Сохранённый вариант крупных цифр SW2019 |
| `font_sw2019_half_10x16_digi.h` | Сохранённый вариант младших разрядов SW2019 |
| `New.RHF` | Исходный файл формата RHF, предоставленный вместе со шрифтами |

Эти файлы не подключены через `#include` в текущих C-модулях. Наличие файла
в списке проекта Keil само по себе не добавляет растры в прошивку.

## Порядок работы

- Растры и сведения об их происхождении хранятся здесь; прежние редакции
  существующих файлов также доступны в истории Git.
- Функции вывода символов остаются в `src/lcd_text.c`, `src/lcd_digits_large.c`
  и `src/lcd_digits_small.c`; драйвер дисплея — в `src/gmg12864.c`.
- Заголовки подключаются относительными путями `../font/...`, одинаковыми
  для сборки Keil, скриптов и ARM-тестов.
- При переносе из `src/` байты шрифтов не менялись. Авторские комментарии
  сохранены; новых преобразований, масштабирования или правок глифов не было.
