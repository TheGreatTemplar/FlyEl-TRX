# Tooling — технологическая оснастка FLyEl-TRX

Здесь размещаются **специально разработанные или доработанные приспособления, стенды и технологическое оборудование**, необходимые для изготовления, подбора, проверки, настройки и калибровки компонентов и узлов трансивера.

Это не перечень покупных лабораторных приборов, а документация на вспомогательные конструкции, созданные в рамках проекта.

## Что хранить

- **Оснастка для подбора компонентов:** приспособления для измерения кварцев по IEC 60444, подбора транзисторов, измерения параметров ферритовых сердечников, проверки варикапов.
- **Измерительные приспособления:** платы переходников, испытательные держатели, согласующие цепи, аттенюаторы, коммутационные стенды.
- **Производственная оснастка:** шаблоны сборки, приспособления для намотки катушек и трансформаторов, механические держатели.
- **Калибровочные и испытательные стенды:** специализированные блоки и методики для проверки LO, ВЧ-трактов и других узлов.

## Рекомендуемый состав папки отдельного приспособления

```text
tooling/
├── README.md
└── <fixture-name>/
    ├── README.md          # Назначение, схема применения, ограничения
    ├── schematic/         # Электрическая схема и файлы САПР
    ├── pcb/               # Плата и производственные данные
    ├── mechanical/        # Чертежи и 3D-модели
    ├── bom/               # Комплектующие
    └── verification/      # Проверка и калибровка приспособления
```

Подкаталоги создаются **по мере необходимости** — не требуется заводить пустые папки.

## Граница с другими каталогами

- `tooling/` — **как устроено и изготовлено** приспособление, как им пользоваться и как проверить его исправность.
- `measurements/` — **результаты измерений** компонентов и узлов трансивера, полученные с помощью приспособления.
- `hardware/` — платы и электрические схемы, **входящие непосредственно в трансивер**.

Ссылки между документацией оснастки и результатами испытаний приветствуются.

## English

Design files and instructions for custom workshop tooling, measurement fixtures, component-matching jigs, assembly aids, and calibration/test setups created to build and validate FLyEl-TRX. Device-specific measurement data belong under `measurements/`; hardware installed in the radio belongs under `hardware/`.
