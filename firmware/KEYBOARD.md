# Клавиатура FlyEl

Источник: [раскладка пользователя](../doc/Раскладка%20клавиатуры%20FlyEl.xlsx).
Первое число в `Key_A_B` — физический вывод CD4017, второе — OUT.
Прерывание EXTI4 и сканер не изменены: в ожидании клавиатура не сканируется.
Команды, удержания, EEPROM и экран обрабатываются в основном цикле.

## Основные команды

| Кнопка | Физическое имя | Короткое нажатие | Удержание строго больше 1 с |
| --- | --- | --- | --- |
| V/M | Key_1_1 | VFO / память | То же действие один раз |
| A=B | Key_1_2 | Копировать частоту и режим A в B | То же действие один раз |
| A/B | Key_1_3 | Выбрать другой VFO | То же действие один раз |
| MW | Key_2_1 | Без записи | Сохранить текущую настройку в выбранный канал |
| M=CL | Key_2_2 | Без очистки | Очистить канал, только если включён выбор CH |
| M>V | Key_2_3 | Без копирования | Перенести занятый канал в активный VFO |
| SPL | Key_4_1 | Включить/выключить состояние SPLIT | То же действие один раз |
| SCN | Key_4_2 | Запустить/остановить сканирование | То же действие один раз |
| VOX | Key_4_3 | Включить/выключить состояние VOX в SSB | То же действие один раз |
| NR | Key_5_1 | DSP-функция отложена | DSP-функция отложена |
| ANF | Key_5_2 | DSP-функция отложена | DSP-функция отложена |
| F-INP | Key_5_3 | FUNC / подтвердить ввод / отменить пустой ввод | Отменить незавершённый ввод |
| NB | Key_6_1 | Включить/выключить состояние NB | Открыть настройку уровня NB |
| COMP | Key_6_2 | Включить/выключить состояние компрессора | То же действие один раз |
| SET | Key_6_3 | Выбрать PO / ALC / SWR | Открыть Quick Set |
| P.AMP | Key_7_1 | Включить/выключить состояние предусилителя | То же действие один раз |
| ATT | Key_7_2 | OFF, −6, −12, −18, −24, −30 дБ, OFF | То же действие один раз |
| TUNER | Key_7_3 | Включить/выключить состояние тюнера | Запрос настройки, тайм-аут 20 с |
| CH | Key_9_1 | Включить/выключить выбор канала | То же действие один раз |
| DOWN / UP | Key_9_2 / Key_9_3 | Канал при CH, иначе диапазон; в меню — строка | Каналы и строки меню: повтор через 600 мс, затем каждые 200 мс. Диапазоны: один переход на нажатие, без повтора |
| MODE | Key_10_1 | USB/LSB, CW/CW-R, RTTY/RTTY-R | SSB → CW → RTTY → AM → SSB |
| FILTER | Key_10_2 | FIL1 → FIL2 → FIL3 для текущего режима | То же действие один раз |
| TS | Key_10_3 | 10 → 100 → 1000 Гц | 10 кГц; следующее нажатие возвращает прежний шаг |

Три кнопки `Key_11_1..3` в таблице не назначены. Они сохраняют диагностические имена.
В AM короткое MODE ничего не меняет. При возврате из AM в SSB восстанавливается USB/LSB.
Оба VFO при включении начинают с 28,200 МГц, LSB; затем настраиваются независимо.
Вторая строка теперь показывает реальный неактивный VFO, демонстрационная частота удалена.

## Ввод частоты и канала

F-INP включает FUNC для одной операции. Дополнительные подписи кнопок:

| Физические кнопки | Вводимые символы |
| --- | --- |
| Key_1_1, Key_1_2, Key_1_3 | 1, 2, 3 |
| Key_2_1, Key_2_2, Key_2_3 | 4, 5, 6 |
| Key_4_1, Key_4_2, Key_4_3 | 7, 8, 9 |
| Key_5_1, Key_5_2 | точка (для частоты не нужна), 0 |

Ввод позиционный, в том же формате, что и основная частота, с разрешением 10 Гц.
На 160/80/40 м доступны **6 цифр** (`_.___.__`), на диапазонах от 10 МГц — **7 цифр** (`__.___.__`).
Точки появляются автоматически и не занимают место в буфере. Нажатие кнопки точки при вводе частоты игнорируется.
Пример на 15 м: **F-INP, 2, 1, 4, 4, 9, 7, 8, F-INP** → `21.449.78` (21,449780 МГц).
Пример на 80 м: **F-INP, 3, 6, 5, 0, 0, 0, F-INP** → `3.650.00`.
Незаполненные позиции показаны подчёркиваниями; при подтверждении правый хвост считается нулями:
`142` на двухзначном диапазоне → `14.200.00`. Лишние цифры не добавляются.
Прямой ввод принимается только в пределах одного из девяти диапазонов таблицы `bands[]`, включая границы.
При вводе частоты другого диапазона он выбирается автоматически. Частоты в промежутках отклоняются с `INPUT ERR`;
прежние частота, диапазон и режим памяти сохраняются. Например, `10.000.00` не принимается, а `10.100.00` включает 30 м.
Широкий GEN через обычный F-INP больше не включается.
Формат фиксируется по выбранному диапазону при входе в FUNC.
На двухзначном диапазоне однозначные МГц вводятся с ведущим нулём.
Энкодер в выбранном КВ-диапазоне останавливается на его нижней/верхней границе при любом шаге.

**CH, F-INP, цифры, F-INP** выбирает канал 1–99, максимум две цифры, без точек. Следующее CH завершает выбор.
Кнопка NR/. при вводе канала удаляет последнюю цифру (Backspace), сбрасывает ошибку
и обновляет тайм-аут. В пустом поле ничего не удаляет и не закрывает ввод.
Цифры при FUNC не выполняют основные команды, даже при длительном удержании.
Пустая повторная F-INP или удержание F-INP отменяет ввод; 10 секунд без принятого символа тоже отменяют его.
Неверное значение не применяется; появляется `INPUT ERR`, доступна отмена удержанием F-INP.
Короткое F-INP после ошибки сразу очищает старое значение и открывает новый ввод той же частоты/канала;
таймер бездействия начинается заново. Ждать 10 секунд не требуется.
Без введённых цифр нецифровая команда использует FUNC однократно и выключает его.

## Память и сканирование

Выделены **99 каналов**, с номерами 1–99. Количество — `MEMORY_CHANNEL_COUNT` в `app_config.h`.
Сохраняются частота, вид излучения, запомненная полоса SSB, номер фильтра и диапазон.
CH выбирает номер; при VFO выбранный канал не заменяет настройку. V/M включает работу с ним.
Выход V/M восстанавливает прежний VFO. M>V переносит выбранный канал в VFO явно.
Пустой канал помечается `BLANK`. Если память ещё загружается — `WAIT`.

Сначала завершается прежнее чтение всей EEPROM для стартового CRC, затем загружаются каналы.
Чтение при включении ничего не форматирует и не записывает.
Область каналов — **0x4000–0x717F**, два 64-байтных слота на канал.
Адреса и формат каналов 1–99 сохранены: прежние записи читаются без преобразования.
Бывший канал 100 больше не выбирается и не участвует в сканировании; его данные не стираются.
Каждая запись содержит сигнатуру FEL1, номер канала, поколение, данные и CRC-16.
MW/M=CL записывают неактивную копию, дожидаются готовности и сверяют чтение со всей записью.
После подтверждённой записи MW номер записанного канала трижды подмигивает:
200 мс погашен / 200 мс виден, всего 1,2 с, затем остаётся видимым.
Очистка M=CL и ошибки мигание не запускают; для другого выбранного канала оно не показывается.
Подтверждение не зависит от текста диагностической строки и не блокирует управление.
Только после этого обновляется кэш. При повреждённой новой копии после перезапуска выбирается прежняя валидная.
Очистка создаёт запись о пустом канале, чтобы старая копия не восстановилась как занятая.
Ошибки записи, WP и отсутствующая память дают `MEM ERR`; успешные операции — `SAVED`/`BLANK`.

Запись ограничена страницей 64 байта. Готовность проверяется ACK-poll после 5 мс, с общим тайм-аутом 20 мс,
согласно [datasheet AT24C256C](https://ww1.microchip.com/downloads/en/DeviceDoc/AT24C128C-AT24C256C-Data-Sheet-DS20006270B.pdf).

SCN в VFO идёт вверх текущим шагом в границах выбранного диапазона и повторяет проход.
В памяти SCN пропускает пустые каналы. При отсутствии занятых каналов останавливается.
Интервал по умолчанию 200 мс; Quick Set позволяет 50–2000 мс с шагом 50 мс.
UP/DOWN останавливает сканирование без одновременной смены диапазона. Энкодер также останавливает его.
Любая другая команда, кроме самой SCN, останавливает проход перед выполнением.
Порог остановки по сигналу/шумоподавителю и отдельные программируемые границы пока не заданы.

### Порядок работы с памятью

**Сохранить настройку:**

1. В режиме VFO настройте частоту, вид излучения и фильтр.
2. Нажмите CH: номер канала доступен для выбора, MEMO мигает.
3. Выберите канал энкодером или UP/DOWN. Для прямого выбора нажмите F-INP,
   введите номер 1–99 и подтвердите F-INP. Например, F-INP, 9, 9, F-INP — канал 99.
4. Удерживайте MW больше секунды и дождитесь SAVED. Занятый канал будет перезаписан.
5. Нажмите CH, чтобы закончить выбор. При выборе канала в VFO текущая настройка не меняется.

**Вызвать канал и вернуться к VFO:**

1. Нажмите V/M для входа в память.
2. Нажмите CH и выберите канал энкодером, UP/DOWN или прямым вводом через F-INP.
   Сохранённая настройка занятого канала применяется сразу; BLANK означает пустой канал.
3. Нажмите CH, чтобы закончить выбор.
4. Повторное V/M вернёт настройку VFO, которая была до входа в память.
   Чтобы вместо этого перенести выбранную запись в VFO, удерживайте M>V больше секунды.

**Удалить канал:** нажмите CH, выберите номер, удерживайте M=CL больше секунды
и дождитесь BLANK. Завершите выбор кнопкой CH. Вне выбора CH очистка не выполняется.

**Сканировать память:** войдите через V/M и нажмите SCN; пустые каналы пропускаются.
Повторное SCN останавливает сканирование. Перед записью/очисткой дождитесь окончания WAIT;
MEM ERR означает, что операция не подтверждена памятью.

## Меню и индикация

Удержание SET: **Quick Set**. UP выбирает строку выше, DOWN — ниже, энкодер меняет значение.
На первой/последней строке переход циклический; в инженерном меню направления те же.
Пункт ENG показывает подсказку SET+FIL. Вход в SERVICE — только сочетанием SET + FILTER.
SET закрывает меню. В окне NB уровень задаётся энкодером 0–100.
Комбинация SET+PWR из описания пока недоступна: физическая кнопка PWR не назначена.

### Инженерное меню SERVICE

Источник дерева: `doc/FLyEl_Service_Menu_Engineering_Spec_v1_0_new_link.docx`.
Первая реализация содержит 17 разделов и 192 пункта со стабильными ID вида 03.06.
Это навигационный каркас и страницы просмотра; редакторы и сохранение калибровок ещё не подключены.

- Одновременно нажать SET + FILTER. Сочетание проверяется по двум удерживаемым кнопкам
  до обработки одиночных действий. Отпустить обе кнопки перед навигацией.
- Энкодер перемещает по списку, с циклическим переходом через край; на LCD видны четыре строки.
- DN или F-INP входит в раздел/пункт. Удержание DN не перескакивает через несколько уровней.
- NR/. или UP возвращает назад; на верхнем уровне закрывает SERVICE.
- Для 03.06, 04.02, 08.06 и 10.04 перед просмотром выбирается диапазон.
- Вход при активном флаге TX отвергается; сочетание не выполняет одиночные SET/FILTER.
  Программный запрет не заменяет ещё не подключённую аппаратную защиту TX.

Пока доступны фактические сведения о текущей ПЧ, АЦП в мВ, состоянии программных ATT/P.AMP,
результате последнего программирования Si5351, типе LCD и двух программных I2C.
Остальные страницы показывают NOT IMPLEMENTED / NEEDS SPEC OR HW; никакие SAVE, RESET,
TX TEST и калибровки не выполняются. Отдельные страницы статуса не означают наличия аппаратного управления.
FUNC, цифровой ввод, TS, MODE, быстрые установки и каналы вне SERVICE сохраняют прежнюю логику.

Верхняя строка показывает имя последней кнопки, FUNC, SCAN или диагностику памяти.
Если длинный режим RTTY-R не оставляет места, сообщение переносится в строку под вторым VFO.
Между видимыми цифрами основной и второй частоты — две пустые строки пикселей; подпись VFO поднята вместе с частотой.
Окно FUNC: SET:/CH: и вводимые символы одним шрифтом 5×7, ровный прямоугольный фон только по ширине текста.
Левый край подписи SET совпадает с началом основной частоты; точки и позиции цифр неподвижны при наборе.
MEMO выровнена по VFOB (x=47). Номер 01–99 показан отдельным жирным шрифтом 8×9,
две цифры с промежутком 1 px занимают x=111–127, y=42–50; правый край закреплён.
Номер виден постоянно на рабочем экране: в VFO, при выборе CH, в памяти и при прямом вводе.
Окно прямого ввода занимает y=30–40, перед номером оставлена пустая строка y=41.
MEMO мигает при активном выборе CH; без выбора горит только в режиме памяти.
Основная частота остаётся видимой. CH в режиме VFO выбирает адрес записи, не вызывает настройку канала:
удержание MW записывает текущую настройку VFO в выбранный канал без переключения V/M.
WAIT/BLANK расположены между MEMO и номером. Растры: `src/font_channel_bold_8x9.h`.
Мигает только MEMO при выборе CH; номер и остальная строка неподвижны. BLANK показана инверсно.
Рамка SPLIT инвертируется при включении.
Общая рамка показывает инверсную надпись **P.AMP** при включённом предусилителе,
инверсное выбранное ослабление при включённом ATT либо обычную **OFF**, когда оба выключены.
Если включены оба, отображается ослабление ATT. Подпись второго VFO — **VFOB**/**VFOA** без пробела.
Дополнительные флаги на рабочем экране: **N** — NB, **C** — COMP, **V** — VOX,
**T** — тюнер, **T\*** — настройка, **F1..3** — фильтр.
Подписи VFOA/VFOB и F1..3 закреплены на x=47; диапазон выровнен по тому же краю,
а для длинной рамки режима сдвинут вправо, чтобы не перекрывать её. Частота и диагностика этот край не меняют.
При выборе CH и работе из памяти фильтр скрыт; строка показывает номер/пустоту канала.

## Что пока существует только программно

По состоянию макета аппаратные блоки не подключены. NB, COMP, P.AMP, ATT, VOX, TUNER,
коммутация вида излучения и фильтров сохраняют состояния и показывают их на экране.
Трёхбитная `panel.att_mask`: bit0 = 6 дБ, bit1 = 12 дБ, bit2 = 24 дБ.
Ступени −36/−42 дБ временно закомментированы в цикле ATT; преобразование всех масок реле сохранено.
Это готовая маска для будущего драйвера реле/74HC595, GPIO ей пока не назначены.
Ширины FIL1/FIL2/FIL3 в герцах ещё не определены.
VOX не запускает PTT; SPLIT хранит состояние и два VFO, физический переход RX/TX ещё не подключён.
PO/ALC/SWR переключают подпись выбранного измерителя; передающие датчики и калибровка отсутствуют.
В приёме нижняя шкала по-прежнему показывает ADC0 как S-метр. NR и ANF не реализованы по указанию в таблице.

## Проверки без платы

`scripts/test.ps1` сохраняет проверки TS, CRC, адресации, страницы EEPROM и жестов через оптимизированный IR.
Для исполнения сценариев настоящим Thumb-кодом Cortex-M3:

```powershell
python -m pip install --target build/test-deps -r tests/requirements.txt
./scripts/test-arm.ps1
```

Путь Python при необходимости: `./scripts/test-arm.ps1 -Python 'C:/Path/to/python.exe'`.
Unicorn нужен только тестам; прошивка и сборка Keil от него не зависят.
Сценарии проверяют нажатия, FUNC, MODE, TS, ATT, память, WP, повреждение записи и восстановление.
Тестовый эмулятор использует дополнительную RAM для модели внешней EEPROM; рабочая прошивка по-прежнему линкуется под 20 КБ SRAM.
`tests/display_arm.c` формирует настоящие кадры LCD для проверки расположения надписей.
Электрические уровни, тайминги физической I2C и сам макет требуют аппаратной проверки.
