# Карта модулей

Прошивка работает без RTOS и HAL. Регистры STM32 доступны через CMSIS.
Задачи основного цикла выполняются кооперативно: короткая порция работы, затем возврат.

## Запуск и время

`main.c` устанавливает 72 МГц от кварца 8 МГц, сохраняет SWD, настраивает ввод, обе I2C, UART, ADC, TIM2 и LCD.
Затем показывает заставку три секунды и передаёт управление приложению.
`app_time.h` объявляет общую базу времени: один тик — 500 мкс.

TIM2 работает на 2 кГц: увеличивает счётчик времени, обслуживает ввод и светодиод.
EXTI4 только маскирует INT и будит клавиатуру. Оба IRQ одного приоритета, чтобы не менять состояние сканера одновременно.
В IRQ нет I2C, LCD, форматирования строк и длительных задержек.

## Приложение

| Файл | Ответственность |
| --- | --- |
| `generator_menu.c` | Координатор: фоновые задачи, кнопки, энкодер и запрос перерисовки |
| `app_state.h` | Внутреннее состояние; меняется только в основном цикле |
| `app_config.h` | Константы макета, номера CLK, параметры экрана |
| `radio_control.c` | Таблицы диапазонов/шагов/ПЧ, ограничение RF, Si5351, применение TS |
| `ts_button.c` | Независимый автомат короткого/длительного нажатия TS |
| `freq_entry.c` | Ручной ввод частоты из логических цифровых клавиш |
| `eeprom_startup.c` | Поиск EEPROM, чтение по 128 байт, CRC, трёхсекундная индикация |
| `text_utils.c` | Числа и добавление строк в заранее выделенные буферы |
| `keyboard.c`, `key_layout.c` | Команды физических клавиш, основные/цифровые назначения |
| `key_gesture.c` | Короткое/длительное нажатие и повтор UP/DOWN |
| `entry_controller.c`, `frequency_parse.c` | FUNC, ввод и проверка частоты/канала, тайм-аут |
| `radio_vfo.c`, `radio_mode.c` | Два VFO, режимы, SPLIT и фильтры |
| `radio_panel.c` | Программные состояния ATT/NB/COMP/VOX/тюнера |
| `memory_control.c` | Выбранный канал, режим памяти и возврат в VFO |
| `memory_store.c`, `memory_record.c` | Две копии записей, CRC, загрузка и проверяемая запись EEPROM |
| `scan_control.c`, `settings_control.c` | Сканирование и меню установок |

Старые логические имена клавиш оставлены для совместимости; команды назначены физическим `Key_A_B`.
`input.c` собирает события, `keyboard.c` применяет действия в основном цикле.
FUNC поглощает весь цифровой жест, поэтому удержание цифры не выполняет MW/M=CL/M>V.
Для TS сохранён исходный отдельный автомат.

## Отображение

| Файл | Что менять здесь |
| --- | --- |
| `ui_screens.c` | Расположение блоков основного экрана и меню |
| `ui_frequency.c` | Числа, точки, интервалы, выравнивание и размеры разрядов |
| `ui_widgets.c` | Рамки, инверсия TX/ATT и подписи 5×7 |
| `ui_smeter.c` | Геометрия шкалы и полосы S-метра |
| `ui_status.c`, `ui_settings.c` | Диагностика, состояния, каналы и меню установок |
| `gmg12864.c` | Буфер 1024 байта, SPI-команды LCD и геометрические примитивы |
| `lcd_text.c` | Tahoma и компактные буквы 5×7 |
| `lcd_digits_large.c` | Terminus и готовые SW2019-растры 17/15 |
| `lcd_digits_small.c` | Цифры 7×11 и 4×6 |
| `font/*.h`, `src/font_*.h` | Пиксельные данные символов |

Публичный API LCD остаётся в `gmg12864.h`.
Рисование меняет RAM-буфер; только `LCD_Update()` передаёт его на экран.
У `LCD_FillRectangle()` размеры включительны: `1, 1` даёт 2×2 пикселя.
Поэтому обычные размеры рамок передаются как `width - 1`, `height - 1`.

## Периферия

- `input.c`: энкодер, CD4017, EXTI4, дребезг и события. В ожидании клавиатура проверяет только флаг активности, GPIO не опрашиваются.
- `i2c_soft.c`: первая программная шина PB6/PB7 для Si5351.
- `si5351.c`: PLLA, Multisynth, упаковка регистров и выходы.
- `i2c2_soft.c`: PB8/PB9, ACK/NACK, repeated START, ограниченное ожидание SCL.
- `at24c256.c`: адресация, границы памяти, потоковый CRC.
- `adc1_app.c`: ADC1 и перевод отсчёта в мВ.
- `spi1.c`: передача LCD с таймаутами флагов SPI.
- `uart1.c`: диагностические строки без printf.

## Как добавлять изменения

Новая кнопка: имя/цифра в `key_layout.c`, команда в `keyboard.c`; жесты обслуживает `key_gesture.c`.
Новый аппаратный узел: отдельный драйвер и вызовы из основного цикла.
Подпись/координата: `ui_screens.c` или `ui_widgets.c`. Форма цифры: данные в `font/`.

ISR владеют состоянием ввода, основной цикл — `menu`, LCD — своим буфером.
Таблицы в `app_state.h` — внутренний интерфейс приложения, а не API драйверов.

## Оставшиеся ограничения

Не реализованы аппаратное RX/TX, RIT, коммутация SPLIT и 74HC595.
NB/COMP/VOX/P.AMP/ATT/TUNER и фильтры пока имеют программные состояния без аппаратного драйвера.
Каналы памяти сохраняются, остальные пользовательские настройки при выключении сбрасываются.
Парсер частоты переработан: дробь накапливается в Гц без переполнения; настройка энкодером использует 64-битный промежуточный результат.
Ожидание ADC блокирующее, без таймаута. Ошибки Si5351 сохраняются в состоянии, но отдельного сообщения на экране ещё нет.
